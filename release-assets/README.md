# Privacy Mirror v0.1.0 extension packages

## Downloads

- `privacy-mirror-chrome-v0.1.0.zip`
- `privacy-mirror-firefox-v0.1.0.zip`

## Install

### Chrome

1. Extract the Chrome ZIP.
2. Open `chrome://extensions`.
3. Enable **Developer mode**.
4. Choose **Load unpacked** and select the extracted directory.

### Firefox

1. Extract the Firefox ZIP.
2. Open `about:debugging#/runtime/this-firefox`.
3. Choose **Load Temporary Add-on**.
4. Select `manifest.json` in the extracted directory.

The Firefox developer package is unsigned and its temporary installation is removed after the browser restarts.
